## Behind the scenes, in plain sight

This repository is a public window into ongoing experiments, software, tools, and ideas from **NetworkLuki**.

## What appears here

- **Teaser cards:** short descriptions, codenames, and broad progress signals.

- **Development notes:** what changed, without exposing implementation details.
- **Reveal posts:** the moment a project is ready to be shown more openly.
